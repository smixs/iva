# Google Calendar: изменение события

1. Найди событие через `gws calendar events list`, пройди все страницы по `nextPageToken`, затем
   получи точный объект через `gws calendar events get`.
2. Покажи название, календарь, дату и время. Для серии уточни область изменения: экземпляр или серия.
3. Для повторяющегося события выбери API-target:
   - вся серия → получи родительское событие по `recurringEventId` экземпляра и используй ID
     родителя как `eventId`;
   - один экземпляр → найди его через `gws calendar events instances`, проверь `recurringEventId`
     и `originalStartTime`, затем используй возвращённый ID экземпляра как `eventId`.
4. Создай patch из полей, явно указанных пользователем, и полного объекта напоминаний.
   Для массивов `attendees`, `recurrence` и `reminders.overrides` собери полный итоговый массив,
   сохраняя элементы за пределами запрошенного изменения.
5. Для изменения напоминаний используй полный итоговый объект:
   `{"useDefault":false,"overrides":[...]}`. Объединяй напоминания в одном массиве, убирай
   одинаковые пары `method + minutes`, используй до пяти значений с методами `popup` и `email`.
   Для остальных изменений сохрани текущий массив `overrides`, а при `useDefault:true` используй
   `Calendar defaults` из CORE. При отсутствии сохранённого профиля уточни напоминания.
6. При наличии участников уточни режим `sendUpdates`: `all`, `externalOnly` или `none`, покажи его
   в dry-run и финальном подтверждении и передай через `--params`.
7. Проверь добавляемый текст на чувствительные сведения. Покажи категории и маскированные
   идентификаторы, а точные значения включи в подготовленный patch. Напомни о возможном доступе
   участников и читателей календаря и повтори предупреждение в финальном подтверждении.
8. Прочитай `gws schema calendar.events.patch` и выполни `gws calendar events patch`
   с `--dry-run`.
9. Покажи итоговые изменяемые поля и запроси явное подтверждение.
10. После подтверждения снова получи API-target и сравни `etag`. При совпадении сразу выполни
    подтверждённый patch с точными значениями. При изменении покажи актуальную версию и запроси
    новое подтверждение.
11. Сообщи изменения из ответа API.

Изменение времени и длительности выполняй по skill `google-calendar-reschedule`.
