# Google Calendar: изменение события

1. Найди событие через `gws calendar events list`, затем получи его через
   `gws calendar events get`.
2. Покажи название, календарь, дату и время. Для серии уточни область изменения: экземпляр или серия.
3. Создай patch из полей, явно указанных пользователем, и полного объекта напоминаний.
4. Для изменения напоминаний используй полный итоговый объект:
   `{"useDefault":false,"overrides":[...]}`. Объединяй напоминания в одном массиве, убирай
   одинаковые пары `method + minutes`, используй до пяти значений с методами `popup` и `email`.
   Для остальных изменений сохрани текущий массив `overrides`, а при `useDefault:true` используй
   `Calendar defaults` из CORE. При отсутствии сохранённого профиля уточни напоминания.
5. При изменении участников уточни режим отправки приглашений и передай выбранный `sendUpdates`:
   `all`, `externalOnly` или `none`.
6. Проверь добавляемый текст на чувствительные сведения. Перечисли найденные сведения, напомни о
   возможном доступе участников и читателей календаря и запроси явное подтверждение. После
   подтверждения сохрани сведения в указанном пользователем поле.
7. Прочитай `gws schema calendar.events.patch` и выполни `gws calendar events patch`
   с `--dry-run`.
8. Покажи итоговые изменяемые поля и запроси явное подтверждение.
9. После подтверждения снова получи событие и сравни `etag`. При изменении покажи актуальную версию
   и запроси новое подтверждение.
10. Выполни запрос в рабочем режиме и сообщи изменения из ответа API.

Изменение времени и длительности выполняй по skill `google-calendar-reschedule`.
