# Google Calendar: удаление события

1. Найди событие через `gws calendar events list`, пройди все страницы по `nextPageToken`, затем
   получи точный объект через `gws calendar events get`.
2. Покажи название, календарь, дату, время и признак повторения.
3. Для повторяющегося события уточни область удаления: один экземпляр или вся серия.
4. Преобразуй область в API-target:
   - вся серия → получи родительское событие по `recurringEventId` экземпляра и используй ID
     родителя как `eventId`;
   - один экземпляр → найди его через `gws calendar events instances`, проверь `recurringEventId`
     и `originalStartTime`, затем используй возвращённый ID экземпляра как `eventId`.
5. При наличии участников уточни режим `sendUpdates`: `all`, `externalOnly` или `none`.
6. Прочитай `gws schema calendar.events.delete`.
7. Выполни `gws calendar events delete` с `--dry-run`, передай `calendarId`, выбранный `eventId` и
   при наличии участников `sendUpdates` через `--params`.
8. Покажи точный API-target и режим уведомлений, затем запроси явное подтверждение.
9. После подтверждения снова получи API-target и сравни `etag`. При совпадении сразу выполни
   подтверждённый delete. При изменении покажи актуальную версию и запроси новое подтверждение.
10. Сообщи результат API.

При нескольких совпадениях покажи варианты с датами, временем и ID и запроси выбор пользователя.
