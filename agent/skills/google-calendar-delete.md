# Google Calendar: удаление события

1. Найди событие через `gws calendar events list`, затем получи его через
   `gws calendar events get`.
2. Покажи название, календарь, дату, время и признак повторения.
3. Для повторяющегося события уточни область удаления: один экземпляр или вся серия.
4. Прочитай `gws schema calendar.events.delete`.
5. Выполни `gws calendar events delete` с `--dry-run` и проверь ID календаря и события.
6. Покажи точный объект удаления и запроси явное подтверждение.
7. После подтверждения снова получи событие и сравни `etag`. При изменении покажи актуальную версию
   и запроси новое подтверждение.
8. Выполни запрос в рабочем режиме и сообщи результат API.

При нескольких совпадениях покажи варианты с датами, временем и ID и запроси выбор пользователя.
