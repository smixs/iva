# Google Calendar: перенос события

1. Найди событие через `gws calendar events list`, затем получи его через
   `gws calendar events get`.
2. Покажи название, календарь, начало, окончание, длительность и признак повторения.
3. Уточни новое начало. При отсутствии новой длительности сохрани исходную длительность.
4. Для серии уточни область переноса: один экземпляр или вся серия.
5. Определи итоговые напоминания: сохрани текущий массив `overrides`, а при `useDefault:true`
   используй `Calendar defaults` из CORE. При отсутствии сохранённого профиля уточни напоминания.
6. Проверь события целевого интервала и покажи совпадения либо пересечения.
7. Для изменения времени прочитай `gws schema calendar.events.patch`, собери `start`, `end` и полный
   объект `{"useDefault":false,"overrides":[...]}`, затем выполни `gws calendar events patch`
   с `--dry-run`.
8. Для переноса между календарями прочитай `gws schema calendar.events.move` и уточни целевой
   календарь. При `useDefault:true` подготовь сначала `gws calendar events patch` с итоговыми
   напоминаниями, затем `gws calendar events move`; выполни оба запроса с `--dry-run`.
9. Покажи итоговые параметры и последовательность запросов, затем запроси явное подтверждение.
10. После подтверждения снова получи событие и сравни `etag`. При изменении покажи актуальную версию
    и запроси новое подтверждение.
11. Выполни запросы в рабочем режиме и сообщи итог из ответа API.

Для события со временем используй RFC3339 и IANA timezone. Для all-day используй `start.date` и
`end.date`; `end.date` указывает следующий день после последнего дня события.

Для нового времени используй часовой пояс из запроса, затем часовой пояс события, затем
`Calendar defaults`.

Передавай поля, относящиеся к переносу. Исходные название, описание, место, участники и напоминания
сохраняются в событии. Перенос между календарями применяется к событиям типа `default`.
